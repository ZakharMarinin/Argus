Add a target

A container registers itself: tag it with the argus.monitor=true label (add argus.probe.url too for an HTTP check) and the watcher picks it up without a restart.

A standalone uptime target has no label to hang off — create one against the backend's own API: 

curl -X POST http://<your argus-backend>/v1/api/targets \
  -H 'Content-Type: application/json' \
  -d '{"name":"my-app","source":"https://myapp.local/health","target_type":"probe"}'

Full request/response shapes are in the backend's Swagger UI at /swagger/index.html.
